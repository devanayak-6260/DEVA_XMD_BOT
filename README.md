📦 Installation

1. Clone Repository

git clone YOUR_REPOSITORY_URL

2. Open Folder

cd DEVA_XMD_BOT

3. Install Dependencies

npm install

4. Start Bot

npm start

5. Connect WhatsApp

- Get the pairing code from the bot console.
- Open WhatsApp.
- Go to Linked Devices.
- Select Link a Device.
- Enter or use the displayed pairing instructions.
